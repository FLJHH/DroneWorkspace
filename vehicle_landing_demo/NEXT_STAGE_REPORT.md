## 3. 静态 baseline 总结

| 指标 | 结果 |
|---|---:|
| 成功次数 / 总次数 | 5 / 5 |
| 成功率 | 100%（仅 5 次同工况样本） |
| 平均 / 最大起飞→触地时间 | 58.651 / 58.828 s |
| 平均 / 最大触地水平误差（Gazebo GT） | 0.341 / 0.364 m |
| 平均 / 最大触地垂直速度绝对值（Gazebo GT） | 0.804 / 0.816 m/s |
| 平均 / 最大触地相对水平速度（Gazebo GT） | 0.826 / 0.849 m/s |
| Tag 丢失发生比例 | 5/5；均发生一次近地短时丢失 |
| 平均 / 最大最长丢失时间 | 0.297 / 0.352 s |
| OFFBOARD 异常 | 0 次 |
| disarm 失败 | 0 次 |
| possible_bounce | 0/5 |

触地是控制器用 Gazebo 高度及水平门限触发 disarm 的时刻，不是接触传感器首次接触时刻。原始 CSV 同时保存 Gazebo GT 与 MAVROS 速度；落点误差、车辆速度、clearance、弹跳判据来自 Gazebo GT，Tag 可见性来自视觉 TF。五轮触发后均未越过 `+0.10 m` 弹跳阈值，因此“未发现明显弹跳”，但不能替代接触力测量。

值得注意的是，触地水平误差已接近代码 0.35 m 判定边界，且相对水平速度约 0.83 m/s；重复成功不等于触地质量充裕。这是进入 TRACK 前应保留的风险指标。

## 4. 0.5 m/s UGV 测试

最终 vehicle-only 记录 45.016 s、864 个样本；稳定段定义为 `t >= 10 s`，共约 35 s。

| 指标 | 结果 |
|---|---:|
| 目标速度 | 0.500000 m/s |
| 稳定段平均实际速度 | 0.499999933 m/s |
| 速度标准差 | 0.000002023 m/s |
| 最小 / 最大速度 | 0.499996108 / 0.500003474 m/s |
| 平均速度绝对偏差 | 约 0.000000067 m/s |
| 稳定段 y 范围 | 1.59e-8 m |
| 终点 x | 约 30.11 m（起点 10.0 m） |
| 稳定性 | 通过：无速度发散、明显横漂、翻车或异常旋转 |

第一次原型测试中实际速度约为零，根因是原控制器最大 900 N 推力不足以克服车体静摩擦。修正后才得到以上结果；没有通过放宽 0.05 m/s 门槛制造成功。数据全部来自 `/gazebo/model_states`。

## 5. 移动情况下 AprilTag

在固定俯视相机的有限视场内，`landing_pad` TF 可见 302/864 个采样点，可见区间约 12.30–28.01 s。该区间车辆 Gazebo x 增量为 7.854 m，视觉 TF x 增量为 7.599 m；视觉 x 对真值的平均误差约 -0.030 m，最大绝对误差约 0.276 m，y 平均误差约 0.007 m。

结论：**Tag TF 在可见区间内连续随车辆同向移动，趋势验证通过；固定相机视场外不可见，不能称全程连续。** 初测还发现测试相机 optical-frame TF 姿态错误，修正并复测后才采用最终数据。

## 6. 移动情况下 YOLO

YOLO 在 409/864 个记录采样点输出有效车辆框，置信度范围 0.330–0.734，均值约 0.634。车辆进入固定相机视场后持续检出，靠近视场边缘以及驶离视场后丢失。此结果说明 0.5 m/s 本身未造成明显推理异常，但当前固定相机布置不能验证全程检测率，也未修改模型或训练数据。

## 7. 当前发现的问题

- **P0：移动末段仍无可靠相对速度闭环。** 当前验证的只是 UGV 和视觉 TF；无人机没有 TRACK 状态，也未进行移动降落。
- **P1：静态触地裕量有限。** 五轮 GT 水平误差平均 0.341 m，接近 0.35 m 门限；相对水平速度平均 0.826 m/s，需在后续 TRACK 阶段先验证速度匹配。
- **P1：近地 Tag 丢失可重复出现。** 五轮均有一次 0.26–0.352 s 丢失；静态目标靠冻结位置尚可，移动目标会形成滞后。
- **P2：系统仍大量依赖 Gazebo 真值。** 本报告明确标注 GT，但路径、clearance 和触地决策尚非纯视觉/机载传感器实现。
- **P2：固定测试相机视场有限。** Tag/YOLO 随车趋势已验证，但检测比例不能作为移动跟踪可用率。

## 8. 是否允许进入下一阶段

**GO：可以开始开发“固定高度 TRACK 移动目标跟踪”。**

依据是静态同工况 5/5 完成、0.5 m/s UGV 速度与直线稳定性通过、Tag TF 在视场内正确随车变化、YOLO 在车辆通过视场时正常检出。这个 GO 只授权下一阶段的固定高度跟踪开发；**不代表允许直接移动下降或移动平台降落**。TRACK 应先输出相对位置/速度误差和丢失恢复数据，在固定高度通过后才讨论 DESCEND。
